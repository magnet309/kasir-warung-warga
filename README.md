# Kasir Pintar Warung Warga

Aplikasi web seluler (mobile-first) untuk membantu pemilik warung mengelola pencatatan transaksi penjualan harian dan pemantauan stok barang secara interaktif.

## Struktur Proyek
Proyek ini memiliki struktur direktori dan berkas sebagai berikut:
- `index.html`: Berisi struktur dokumen HTML semantik untuk antarmuka utama aplikasi.
- `styles.css`: Berisi pengaturan gaya, tata letak, dan custom properties CSS secara modular.
- `script.js`: Berisi logika JavaScript murni untuk interaktivitas dan perpindahan tampilan antar halaman.
- `README.md`: Dokumentasi penjelasan proyek.

## Cara Menjalankan
1. Unggah seluruh berkas (`index.html`, `styles.css`, `script.js`, dan `README.md`) ke folder utama (akar) repositori publik GitHub Anda (`https://github.com/magnet309/kasir-warung-warga`).
2. Aktifkan fitur **GitHub Pages** melalui menu **Settings** > **Pages** di repositori Anda dengan memilih branch `main` dan folder `/ (root)`.
3. Buka tautan GitHub Pages yang dihasilkan untuk menjalankan dan melihat pratinjau aplikasi secara langsung di peramban.
