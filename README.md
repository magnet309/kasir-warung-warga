# Kasir Pintar Warung Warga

Aplikasi web seluler (mobile-first) untuk membantu pemilik warung mengelola pencatatan transaksi penjualan harian dan pemantauan stok barang secara interaktif.

## Struktur Proyek
- index.html: Berisi struktur dokumen HTML semantik.
- styles.css: Berisi pengaturan gaya dan custom properties CSS.
- script.js: Berisi logika JavaScript untuk interaktivitas.
- README.md: Dokumentasi proyek.

## Cara Menjalankan
1. Unggah seluruh berkas ke repositori publik GitHub (`magnet309/kasir-warung-warga`).
2. Aktifkan GitHub Pages melalui menu Settings > Pages.
3. Buka tautan GitHub Pages untuk menjalankan aplikasi.
